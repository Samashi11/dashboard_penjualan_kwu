Sambal Lele 2.0
=====================

Sambal Lele 2.0 adalah sebuah aplikasi berbasis web yang dibuat untuk memenuhi kebutuhan UMKM (Usaha Mikro Kecil) di Indonesia. Aplikasi ini dibuat dengan menggunakan bahasa pemrograman PHP dan framework Laravel. Aplikasi ini juga menggunakan database MySQL untuk menyimpan data.
